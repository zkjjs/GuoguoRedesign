# Guoguo Apple 风格重构设计规格

日期：2026-07-20  
状态：已确认
目标平台：iPhone、iPad，iOS 15 及以上

## 1. 背景与目标

基于用户已授权分析的 Guoguo IPA，重建一个可维护的 Flutter 客户端。新客户端继续使用既有后端协议和 AliyunPlayer 播放能力，但不复用原应用已编译的 Flutter 页面，也不对 Dart AOT 做界面补丁。

重构目标：

- 将现有界面替换为深黑、克制、沉浸式的 Apple 影院风格。
- 保留完整影视浏览、账号、会员、任务、金币、评论、下载和播放能力。
- 将接口、播放器和 UI 隔离，后续任一层更新都不要求重写其他层。
- 保持普通操作即时反馈、手势跟手、动画可中断，并尊重系统辅助功能偏好。

## 2. 已确认的产品范围

### 2.1 底部导航

使用四个一级入口：

1. 频道
2. 搜索
3. 收藏
4. 我的

移除“发现”一级入口。应用启动后默认进入频道页。

### 2.2 频道页

频道页使用“大幅精选主视觉 + 横向片单”结构：

- 顶部精选主视觉支持手动横滑，不自动轮播，不自动播放预告。
- 主视觉提供标题、年份、类型、清晰度、播放和加入片单操作。
- 下方依次展示继续观看、热门电影、最新剧集及服务端配置的分类片单。
- 继续观看显示集数、剩余时间和播放进度；最新剧集显示更新集数。
- 数据分区独立加载；单个分区失败不得阻断整个页面。

### 2.3 搜索页

- 使用可展开的系统风格搜索框。
- 空状态显示搜索历史和热门关键词。
- 输入采用防抖请求，提交后记录本地历史。
- 结果使用海报网格，并支持类型、年份及排序筛选。
- 无结果、网络失败与加载更多失败均使用页面内状态，不弹阻断式对话框。

### 2.4 收藏页

- 分类包含电影、剧集、动漫。
- 状态筛选包含全部、未看完、已看完。
- 显示本地观看进度；登录后与服务端收藏状态同步。
- 离线操作进入待同步队列，恢复网络后按时间顺序提交。

### 2.5 我的

- 顶部展示账号头像、昵称、登录状态和会员有效期。
- 历史、下载、消息和设置使用标准分组列表。
- 任务与金币保留，但收进“我的”，不占用一级导航。
- 未登录用户可浏览公开内容；触发会员、收藏同步或任务功能时再请求登录。

## 3. 视觉与动效规范

视觉方向采用 Cinema Glass：

- 应用始终使用深色影院主题，不随系统浅色模式切换；系统外观只影响键盘、分享面板等系统界面。
- 主背景为接近纯黑的影院色，内容层级主要依靠明度、间距和字号建立。
- 白色用于正文和主要操作；红色只用于选中状态、播放进度、错误及关键操作。
- 毛玻璃仅用于底部导航、播放器控制层、底部面板及少量浮层，禁止浅色玻璃叠加。
- 大幅图片使用渐变遮罩确保文字可读，不在海报上堆放多个标签。
- 默认使用系统字体和动态字号；布局随字号放大，不固定文字容器高度。

动效规则：

- 按下时立即提供轻微缩放或明度反馈，操作在抬起时提交。
- 横滑内容与手指 1:1 跟随，并保留抓取位置。
- 松手后使用临界阻尼或近临界阻尼弹簧；只有甩动手势允许轻微动量感。
- 转场从当前屏幕呈现值开始，允许用户在动画中途反向操作。
- 开启“降低动态效果”后，以 150–200 ms 淡入淡出替代大范围位移和弹簧。
- 开启“降低透明度”后，将玻璃表面替换为近实色高对比背景。

## 4. 技术架构

采用 Flutter 新前端与原生 AliyunPlayer 适配层：

### 4.1 Core

- `network`：HTTP 客户端、公共请求头、令牌刷新、脱敏日志。
- `auth`：账号状态、Keychain 凭据、登录失效处理。
- `routing`：四个主导航栈和详情/播放全屏路由。
- `theme`：Cinema Glass 设计令牌、动态字号和辅助功能适配。
- `storage`：SQLite、图片缓存、用户偏好和离线同步队列。

### 4.2 Features

- `channel`
- `search`
- `favorites`
- `profile`
- `membership`
- `tasks`
- `video_detail`
- `player`
- `comments`
- `downloads`

每个功能模块只依赖抽象仓储接口，不直接读取 HTTP JSON 或播放器 SDK 对象。

### 4.3 API Adapter

已从授权 IPA 静态确认的接口族包括：

- `/app/video/list`
- `/app/video/detail`
- `/app/video/search`
- `/app/video/play`
- `/app/playaddr/get/token`
- `/app/playaddr/v3/get`
- `/app/collect*`
- `/app/history*`
- `/app/users/*`
- `/app/vip_price/*`
- `/app/task/*`
- `/app/vod_comment/*`

适配器负责将服务端字段映射为稳定领域模型。实现阶段通过授权测试账号记录真实请求和响应，补全参数、签名顺序、错误码与令牌有效期；不得在代码库、日志或测试快照中保存真实令牌。

### 4.4 Player Bridge

播放器桥接层封装 AliyunPlayer，向 Flutter 暴露稳定状态：空闲、取址、准备、播放、暂停、缓冲、结束和错误。

桥接层负责：

- 加载和停止播放地址。
- 清晰度、倍速、播放进度、音量及画中画。
- 前后台切换、音频会话和横竖屏状态恢复。
- 播放事件去重和线程切换。

投屏和下载使用独立服务，不与屏幕 Widget 生命周期绑定。

## 5. 播放体验与数据流

### 5.1 页面结构

竖屏详情页顶部为 16:9 播放器，下方依次展示标题信息、关键操作、线路/选集、简介及评论。旋转设备进入横屏全屏，退出全屏后恢复原播放位置。

线路和选集使用底部毛玻璃面板。下载、收藏、分享和反馈保留在竖屏详情页，降低全屏控制密度。

### 5.2 全屏操作

- 单击显示或隐藏控制层，控制层闲置后自动收起。
- 水平滑动调整进度；左侧垂直滑动调整亮度；右侧垂直滑动调整音量。
- 支持锁定、清晰度、倍速、弹幕、画中画、投屏和下一集。
- 所有手势都提供视觉反馈，并支持取消或反向操作。

### 5.3 播放链路

播放请求严格按以下状态流转：

1. 加载影片详情和当前集信息。
2. 请求 `PLAY-TOKEN`。
3. 携带授权头请求播放地址。
4. 从响应解析 `raw_play_url` 及必要请求头。
5. 将地址交给 AliyunPlayer。

播放令牌失效只自动刷新一次；再次失败展示可操作错误。播放地址只在必要生命周期内存在，不写入持久日志或长期缓存。观看进度以影片、线路和集数为联合键保存。

## 6. 完整播放功能

本次保留：

- 多线路切换
- 选集与自动下一集
- 清晰度与倍速
- 弹幕
- 画中画
- DLNA/投屏
- 离线下载
- 收藏、分享、反馈及评论

任一附加功能失败不得中断基础播放。例如投屏发现失败只影响投屏入口，评论加载失败不影响播放器。

## 7. 错误、安全与隐私

- 网络错误在对应内容区域显示重试和缓存状态。
- 登录过期由统一认证层刷新；刷新失败回到登录页，但保留本地历史、收藏和下载。
- 播放错误区分令牌失效、线路失效、格式不支持和网络中断。
- 用户令牌、播放令牌和敏感账号数据保存在 iOS Keychain。
- 生产日志对 Token、签名、手机号、用户 ID 和播放地址进行脱敏。
- 仅在用户触发相应功能时请求通知、照片、局域网和媒体库权限。
- 不绕过账号权限、服务端授权或媒体 DRM。

## 8. 性能策略

- 海报按显示尺寸请求并进行内存/磁盘两级缓存。
- 频道分区按视口懒加载，预取仅覆盖下一屏。
- 播放器实例在详情与全屏间复用，避免旋转时重新取址。
- 页面动画仅使用位移、缩放和透明度等合成友好属性。
- 低内存通知到达时清理非可见大图与预取数据，不终止当前播放。

## 9. 测试与验收

### 9.1 自动测试

- 接口模型、签名输入、令牌刷新及播放地址解析单元测试。
- 频道、搜索、收藏、我的和详情页 Widget 测试。
- 关键页面在标准字号与最大辅助字号下进行视觉快照测试。
- 播放器状态机覆盖加载、播放、暂停、缓冲、切集、切线路、失败重试及后台恢复。
- 使用模拟服务覆盖超时、空响应、令牌过期、部分分区失败和离线恢复。

### 9.2 设备验收

- iOS 15、当前 iOS 主版本及 iPad。
- 小屏 iPhone、标准尺寸 iPhone 和高刷新率设备。
- 竖屏详情与横屏全屏无播放位置丢失。
- 降低动态效果、降低透明度、粗体文本和大字号可用。
- 普通浏览与播放路径不依赖任务、金币或评论服务可用性。

## 10. 交付物

- 可构建的 Flutter 工程。
- iOS AliyunPlayer、投屏及下载桥接代码。
- API 适配层与脱敏的接口契约测试。
- Cinema Glass 设计令牌和可复用组件。
- 自动测试与构建说明。
- 经授权测试环境验证的 iOS 安装包。

## 11. 非目标

- 不恢复原 Flutter 源码或复制原页面实现。
- 不修改、绕过或伪造服务端权限。
- 不在首版加入社交推荐、直播、跨平台桌面端或新的付费模型。
- 不为 iOS 14 及以下系统提供兼容实现。

## 12. 完成标准

满足以下条件才视为完成：

1. 四个主导航和详情/播放器流程完整可用。
2. 授权账号可完成登录、浏览、取址和播放。
3. 低网速、令牌失效和线路故障都有明确恢复路径。
4. 完整播放功能不降低基础播放稳定性。
5. 自动测试通过，并在约定设备矩阵完成关键路径验收。
6. UI 与已确认的 Cinema Glass 视觉、频道布局和动效规则一致。
